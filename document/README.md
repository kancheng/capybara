## 概述 / Overview

Capybara 是一個專為機器學習工作流程設計的綜合性工具，從環境配置到模型部署，提供一站式的解決方案。

Capybara is a comprehensive tool designed for machine learning workflows, providing a one-stop solution from environment configuration to model deployment.

### 主要功能 / Main Features

- **環境管理** / Environment Management：自動檢測和管理 Python 環境
- **數據處理** / Data Processing：高效的數據預處理和增強
- **數據標註** / Data Annotation：直觀的圖像和數據標註工具
- **格式轉換** / Format Conversion：支持多種數據格式轉換
- **模型訓練** / Model Training：簡化的模型訓練流程
- **模型匯出** / Model Export：多平台模型導出支持

### 系統要求 / System Requirements

- Windows 10/11 或更高版本
- Python 3.8 或更高版本
- CUDA（可選，用於 GPU 加速）
- 至少 4GB RAM

## 快速開始 / Quick Start

1. 首先完成[環境設定](environment-setup.md)
2. 準備您的數據集
3. 使用[數據標註](data-annotation.md)工具標註數據
4. 進行[模型訓練](model-training.md)
5. [匯出模型](model-export.md)用於部署
