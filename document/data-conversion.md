# 數據格式轉換 / Data Format Conversion

數據格式轉換模塊提供不同標註格式之間的轉換功能，方便在不同工具和框架之間使用數據。

The data format conversion module provides conversion between different annotation formats, facilitating data usage across different tools and frameworks.

## 狀態 / Status

🚧 **規劃中** / In Planning

本模塊目前正在規劃和開發中。

This module is currently being planned and developed.

## 預期功能 / Planned Features

- **支持的格式** / Supported Formats
  - YOLO → COCO
  - COCO → YOLO
  - Pascal VOC → YOLO
  - YOLO → Pascal VOC
  - 自定義格式轉換

- **批量轉換** / Batch Conversion
  - 整個數據集轉換
  - 選擇性轉換
  - 轉換進度顯示

- **格式驗證** / Format Validation
  - 輸入格式驗證
  - 輸出格式驗證
  - 錯誤報告

- **轉換選項** / Conversion Options
  - 類別映射配置
  - 坐標系統轉換
  - 圖像路徑處理
