# 數據標註 / Data Annotation

數據標註模塊提供直觀的圖像和數據標註工具，支持多種標註格式。

The data annotation module provides intuitive image and data annotation tools, supporting multiple annotation formats.

## 狀態 / Status

🚧 **規劃中** / In Planning

本模塊目前正在規劃和開發中。

This module is currently being planned and developed.

## 預期功能 / Planned Features

- **圖像標註** / Image Annotation
  - 邊界框（Bounding Box）標註
  - 多邊形（Polygon）標註
  - 關鍵點（Keypoint）標註
  - 分割掩碼（Segmentation Mask）標註

- **標註格式支持** / Annotation Format Support
  - YOLO 格式
  - COCO 格式
  - Pascal VOC 格式
  - 自定義格式

- **標註工具** / Annotation Tools
  - 快捷鍵支持
  - 批量標註
  - 標註驗證
  - 標註編輯和刪除

- **標註管理** / Annotation Management
  - 標註文件組織
  - 標註進度追蹤
  - 標註質量檢查
